What it does

Core Features

Everything you need for a CLI news digest

Wikipedia Summary Fetch
Takes user input and fetches a 5-sentence summary, article URL, and top categories using the Wikipedia Python library.
wikipedia
Formatted Table Output
Displays article information and readability metrics in a clean fancy_grid format using the Tabulate library.
tabulate
QR Code Generator
Generates a PNG QR code from the article URL and saves it in the project folder. Scan it with a mobile device to access the article instantly.
qrcode
Readability Score
Calculates and displays Flesch Reading Ease, Kincaid Grade Level, word count, and difficulty rating using the Textstat library.
textstat
.env Configuration
Configures app name, version, and other settings using python-dotenv. Makes it easy to add future API keys.
python-dotenv
Smart Disambiguation
Automatically identifies the most relevant page when multiple Wikipedia results are available.
auto-suggest

Quick Start

Installation

6 steps, 5 minutes to get started.

01
Clone the Repository
git clone https://github.com/your-username/cli-news-digest.git
cd cli-news-digest
02
Create Virtual Environment
python -m venv venv
# Windows: venv\Scripts\activate
# Mac/Linux: source venv/bin/activate
03
Install Dependencies
pip install -r requirements.txt
04
Create .env File
# .env
APP_NAME=CLI News Digest
VERSION=1.0.0
05
Run the Application
python news_digest.py
06
Enter a Topic
Topic: Artificial intelligence
